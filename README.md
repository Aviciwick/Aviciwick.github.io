## 🛠️ Tech Stack & Features

- **Zero Dependency**: Pure static HTML5/CSS3/JavaScript, zero node_modules/framework bloat.
- **Single-Video Playback**: Native video manager that automatically pauses background media when a new video plays.
- **One-Gesture Screen Snap**: Smooth magnetic transitions between the Hero intro and featured project cards.
- **Fast-Start Media**: All videos encoded with H.264/AAC + `+faststart` for zero-buffer instant playback on GitHub Pages.
